# Generated tile VFX art source

These 16 transparent PNG atlases were generated with the built-in imagegen
tool for the October 2026 VFX matrix review. Each source is 2172 × 724 px:
three 724 px cells in **Physical, Special, Status** order. Canvas crops the
cells at draw time; the source files are preserved so individual subjects can
be revised. Poison and Fighting use their focused project-owned pixel/canvas
art instead. Normal Physical, Fire Special, and Fairy Status keep their
previously approved focused studies.

The shared generation brief requested independent pixel-art cutouts in a
strict horizontal three-cell sheet, transparent gutters and background, crisp
pixel clusters, a readable 64–80 px silhouette, detailed focal shapes, sparse
small particles, and no characters, floor, text, UI, or panel borders. Each
file added the following specific Physical / Special / Status subjects:

These files are original generated art for this project. The source prompts
describe generic elemental effects and do not request assets from another
game. The review renderer supplies timing, masks, per-tile seeds, and
supporting marks independently of the atlases. When promoting a cell, retain
the approved visual and optimize/export only that cell's needed textures.
